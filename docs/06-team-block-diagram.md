## Introduction

Fill-A-Bot is an automated liquid dispensing system designed to measure and dispense a selected amount of liquid. The system is divided into multiple subsystems responsible for user control, pump operation, flow sensing, and liquid amount sensing. Each subsystem uses a PIC18F57Q43 Curiosity Nano and communicates with the main controller through the team's 8-pin ribbon cable connection. The team block diagram documents how these subsystems are connected and how information is transferred between them using I2C communication.

## System Architecture

Fill-A-Bot uses a hub-and-spoke architecture consisting of one main controller and three slave subsystems. The main controller serves as the central communication point for the Pump Control, Flow Sensing, and Liquid Amount Sensing subsystems.

The microcontrollers communicate using I2C. The team uses 8-pin ribbon cable connectors between boards, with Pin 1 assigned to SDA, Pin 2 assigned to SCL, and Pin 8 reserved for GND.

## Communication

The Fill-A-Bot subsystems communicate using I2C. The team uses 8-pin ribbon cable connectors to connect the main controller to the slave subsystems.

The current ribbon cable pin assignments are:

| Pin | Function |
| --- | --- |
| 1 | SDA |
| 2 | SCL |
| 3 | Reserved / Unused |
| 4 | +5v |
| 5 | Reserved / Unused |
| 6 | Reserved / Unused |
| 7 | Reserved / Unused |
| 8 | GND |

SDA is used for bidirectional data communication between the main controller and slave controllers. SCL is the clock signal generated by the main controller. Each slave controller will use a unique I2C address.
